1. Responsable y contacto

El contacto para asuntos relacionados con este sitio y las comunicaciones de soporte de Fred Memoria Retro es akibet.apple@gmail.com. Puedes escribir a esta dirección para preguntas sobre privacidad o el uso de la información enviada por correo.

2. Alcance de este aviso

Este aviso describe el funcionamiento del sitio web informativo de Fred Memoria Retro y el tratamiento de mensajes enviados voluntariamente a su correo de contacto.

La aplicación móvil es un producto distinto de este sitio. Sus prácticas de privacidad —incluyendo servicios de terceros, análisis, diagnóstico o sincronización, si los hubiera— deben confirmarse en la versión de la app que se publique. No debe interpretarse este aviso como una certificación de las prácticas técnicas de una compilación no verificada.

3. ¿Qué información se trata?

Al visitar el sitio: las páginas son estáticas. No incluyen formularios de registro, cuentas de usuario, publicidad personalizada ni scripts propios de analítica o seguimiento. El servicio de alojamiento puede procesar datos técnicos de conexión conforme a sus propias políticas.

Al enviar un correo: recibimos la dirección de email, el contenido del mensaje y los datos que decidas compartir. Te recomendamos no incluir contraseñas ni información personal innecesaria.

Datos de partidas: el sitio web no dispone de una función para recibir puntuaciones o registros de juego. Las funciones y el almacenamiento de datos dentro de la aplicación móvil deben comprobarse de manera independiente.

4. Finalidades

Utilizamos la información enviada por correo para responder consultas, atender reportes de errores, dar soporte y recibir comentarios o sugerencias. No vendemos la información que nos envías para obtener soporte.

5. Alojamiento y proveedores externos

Este sitio está preparado para alojarse en GitHub Pages, servicio operado por GitHub. Al acceder, GitHub puede tratar información técnica, como direcciones IP y registros de acceso, conforme a sus condiciones y política de privacidad. Consulta la declaración de privacidad de GitHub.

Si decides enviar un correo electrónico, la comunicación también se procesará a través de tu proveedor de correo y del servicio de correo utilizado por el responsable del sitio.

6. Conservación y seguridad

Los mensajes de soporte se conservan durante el tiempo razonablemente necesario para atender la consulta, realizar seguimiento y cumplir obligaciones aplicables. Se procura limitar el acceso a la información a quien necesite atenderla. Ninguna transmisión por internet puede garantizarse completamente segura.

7. Tus derechos y solicitudes

Puedes solicitar información, corrección o eliminación de los datos que hayas proporcionado por correo, sujeto a las obligaciones legales aplicables. Envía tu solicitud a akibet.apple@gmail.com, indicando el correo desde el que nos contactaste y qué necesitas.

Si una persona menor de edad requiere asistencia, recomendamos que el mensaje lo envíe su madre, padre o tutor.

8. Cambios al aviso

Este aviso podrá actualizarse cuando cambien el sitio web, las funciones del producto o los requisitos aplicables. La fecha de revisión se mostrará al principio de esta página.
