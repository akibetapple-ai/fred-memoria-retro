Aviso de privacidad
de la aplicación iOS

Esta política explica cómo funciona la privacidad de Fred Memoria Retro para iPhone. No describe el tratamiento de información técnica del sitio web informativo.

Última actualización: 2 de noviembre de 2026Contacto: akibet.apple@gmail.com

Resumen: el juego no recopila ni envía datos personales o estadísticas al desarrollador ni a servicios de analítica. Los nombres y récords se guardan solo en el iPhone. No hay publicidad de terceros. Jugar no requiere internet; visitar el aviso publicado en la web sí lo requiere.

01. Responsable y contacto

Akibet Software es responsable de la publicación de Fred Memoria Retro. Para consultas relativas a la privacidad de la aplicación, escríbenos a akibet.apple@gmail.com.

Este aviso se refiere exclusivamente a la aplicación móvil para iPhone. Las visitas al sitio web y los correos de soporte se explican en el aviso de privacidad del sitio web.

02. Alcance y funcionamiento

Fred Memoria Retro es un juego de memoria visual y auditiva dirigido al público general, no exclusivamente a niños. No exige crear una cuenta, registrarse, iniciar sesión, proporcionar datos de contacto ni acceder a servicios externos para jugar.

Las partidas y funciones principales operan sin conexión a internet. La consulta voluntaria de un enlace a este aviso en su versión web sí requiere conexión.

03. Información almacenada únicamente en el dispositivo

El juego utiliza almacenamiento local en el iPhone para recordar los siguientes elementos:

  • Nombre o apodo: el que el jugador escribe voluntariamente al guardar un resultado en el Top Ten. También puede elegir «Cancelar» y no guardar el registro.
  • Puntuaciones y progreso: puntos, nivel, grado de dificultad, mejores resultados y registros necesarios para el Top Ten.
  • Preferencias del juego: por ejemplo, activación o desactivación del sonido.

Estos datos permanecen en el dispositivo. La aplicación no los envía a Akibet Software ni a servidores de terceros. El desarrollador no tiene acceso remoto a los nombres o puntuaciones almacenados localmente.

04. Para qué sirve el almacenamiento local

El almacenamiento local se utiliza para mostrar récords, calcular y recordar mejores puntuaciones, mantener opciones elegidas por el usuario y facilitar la continuidad de la experiencia del juego.

No se utiliza para publicidad personalizada, análisis comerciales, seguimiento entre apps o sitios, creación de perfiles de usuarios ni identificación del dispositivo.

05. Analítica, publicidad y comunicación con terceros

Sin SDK de analíticaSin anuncios de tercerosSin rastreoSin cuentas

La aplicación no incorpora servicios de analítica de terceros, redes publicitarias ni SDK de rastreo. No recopila ni transmite a Akibet Software datos de uso, ubicación, contactos, identificadores de dispositivo ni información personal para ningún fin.

No comparte con terceros nombres, récords, estadísticas de partidas o preferencias. No utiliza servicios externos de autenticación, sincronización ni procesamiento de datos para que el juego funcione.

La descarga y distribución mediante la App Store, los eventuales informes gestionados por el sistema iOS y otros servicios propios de Apple se rigen por las políticas y ajustes de Apple, independientes del almacenamiento local del juego.

06. Acceso voluntario a la versión web del aviso

La aplicación puede ofrecer un enlace a https://akibetapple-ai.github.io/fred-memoria-retro/privacidad.html. Solo al abrir voluntariamente la página web se utiliza internet; no se necesita para jugar.

La página pública se aloja en GitHub Pages. Al visitarla, el servicio de alojamiento puede procesar datos técnicos de conexión conforme a sus propias prácticas. El aviso del sitio web explica este tratamiento por separado.

07. Conservación y eliminación de datos locales

Las puntuaciones y nombres guardados permanecen en el iPhone hasta que el usuario los elimine mediante Configuración → Borrar récords, borre los datos correspondientes o desinstale la aplicación. Las preferencias se conservan hasta que se cambian o se elimina la aplicación.

Como Akibet Software no recibe estos registros, no puede consultarlos, recuperarlos ni borrarlos de forma remota. Si el dispositivo utiliza copias de seguridad del sistema, su contenido y conservación dependen de los ajustes del usuario y de los servicios de Apple.

08. Opciones de privacidad y solicitudes

Para controlar los datos del juego, puedes cancelar el guardado de una puntuación, usar Borrar récords y modificar las preferencias. Para eliminar los datos locales restantes, puedes desinstalar la app.

Si nos escribes al correo de soporte, los datos que envíes por ese medio se tratarán según el aviso de privacidad del sitio web y contacto. Puedes consultar o solicitar la rectificación o eliminación de esa comunicación escribiendo a akibet.apple@gmail.com, con sujeción a las obligaciones legales aplicables.

09. Cambios en el aviso

Este aviso podrá actualizarse si cambian las características del juego, sus prácticas de privacidad o los requisitos aplicables. La fecha de la última revisión aparecerá al inicio de la página. Si se incorpora un nuevo tratamiento de datos, se actualizará la información correspondiente antes de su publicación.
