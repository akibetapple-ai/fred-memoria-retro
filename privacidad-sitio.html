Aviso de privacidad
del sitio web

Esta política se refiere exclusivamente a la navegación en el sitio informativo de Fred Memoria Retro y a los mensajes que los visitantes envían voluntariamente al correo de soporte.

Última actualización: 2 de noviembre de 2026Contacto: akibet.apple@gmail.com

Resumen: nuestro sitio no integra herramientas propias de analítica ni publicidad personalizada. El alojamiento GitHub Pages puede procesar datos técnicos de conexión y, si nos escribes, trataremos tu correo y mensaje únicamente para prestar soporte.

01. Responsable y contacto

Akibet Software administra el sitio informativo de Fred Memoria Retro y atiende los mensajes voluntarios de soporte. Para preguntas sobre privacidad o para ejercer derechos relativos a los datos que nos hayas enviado, escribe a akibet.apple@gmail.com.

02. Alcance de este aviso

Este aviso se aplica únicamente al sitio web informativo alojado en akibetapple-ai.github.io/fred-memoria-retro y a las comunicaciones recibidas por su correo de contacto.

El juego para iPhone es un producto distinto. Sus prácticas —como las puntuaciones locales y la ausencia de SDK de publicidad o analítica— se detallan en el aviso de privacidad de la aplicación móvil.

03. Datos técnicos al visitar el sitio

El sitio publica páginas informativas estáticas. No incorpora formularios de creación de cuentas, scripts propios de analítica, publicidad personalizada ni mecanismos propios de seguimiento de visitantes.

El servicio de alojamiento, GitHub Pages, puede tratar información técnica relacionada con la solicitud de las páginas, como la dirección IP, datos del navegador, fecha y hora y registros de acceso, conforme a sus propias políticas. Akibet Software no utiliza esa información para identificar usuarios del juego.

Consulta la Declaración de privacidad de GitHub para información sobre el tratamiento del proveedor de alojamiento.

04. Datos que proporcionas al escribirnos

Si envías voluntariamente un correo a akibet.apple@gmail.com, podremos recibir tu dirección de correo electrónico, el asunto, el contenido del mensaje, los archivos adjuntos y cualquier otro dato que decidas compartir.

Te recomendamos no incluir contraseñas, información financiera ni datos personales innecesarios. El juego no envía automáticamente tu correo ni tus registros locales a Akibet Software.

05. Finalidades del uso de datos de contacto

Utilizamos la información remitida por correo únicamente para responder consultas, ofrecer soporte, atender reportes de errores y dar seguimiento a solicitudes sobre Fred Memoria Retro. No vendemos los mensajes recibidos ni los empleamos para crear perfiles publicitarios.

No solicitamos una cuenta de usuario para navegar en este sitio.

06. Proveedores y comunicaciones con terceros

GitHub Pages presta el servicio de alojamiento y puede procesar información técnica de conexión bajo sus propias condiciones y políticas. Las comunicaciones por email también pasan por el proveedor de correo del remitente y el servicio utilizado para recibirlas, sujetos a sus respectivas políticas.

El sitio puede enlazar a servicios externos, como App Store o GitHub. Al abrirlos voluntariamente, se aplican sus propias políticas de privacidad.

07. Conservación, seguridad y eliminación

Los mensajes recibidos por soporte se conservan durante el tiempo razonablemente necesario para responder, hacer seguimiento y cumplir obligaciones legales aplicables. Se procura limitar el acceso a estas comunicaciones al personal que deba atenderlas.

Si solicitas eliminar un mensaje, revisaremos la petición y lo eliminaremos cuando corresponda, salvo que exista una obligación de conservarlo. No podemos eliminar directamente los registros técnicos que GitHub gestione por cuenta propia; para ello deberás dirigirte al proveedor correspondiente.

08. Tus derechos y cómo contactarnos

Puedes solicitar información, acceso, rectificación o eliminación de los datos que hayas enviado a nuestro correo, de acuerdo con las disposiciones aplicables. Escríbenos a akibet.apple@gmail.com e indica, en lo posible, el correo utilizado y el motivo de tu solicitud.

Si necesitas información o ejercer derechos sobre datos tratados directamente por GitHub, consulta los procedimientos y canales de su declaración de privacidad.

09. Actualizaciones de este aviso

Este aviso se podrá modificar para reflejar cambios en el sitio, sus servicios de alojamiento, las prácticas de contacto o los requisitos legales. La fecha de actualización se mostrará al comienzo de la página.
